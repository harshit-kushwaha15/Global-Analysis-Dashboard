# Global-Analysis-Dashboard
Interactive Data Analytics dashboard built using Python, Pandas, NumPy, SQL, and Power BI. Analyzed global sales and customer data to identify sales trends, customer behavior, product performance, revenue, profit, and regional insights. Developed interactive KPIs, charts, and filters to support data-driven business decisions.
# 🌍 Global Analysis Dashboard

## 📌 Project Overview

**Global Analysis Dashboard** is a data analytics and business intelligence project developed to analyze global sales and business performance. The dashboard transforms raw data into interactive visualizations, KPIs, and actionable insights to support data-driven business decisions.

## 🎯 Objectives

* Analyze global sales and business performance.
* Clean and transform raw datasets.
* Identify sales trends and patterns.
* Monitor key performance indicators (KPIs).
* Compare performance across different regions and categories.
* Create interactive dashboards for better decision-making.
